# JustPlayAudioEx

A lightweight desktop audio player for Windows, focused on local music playback and WASAPI audio output.

## Features

- WASAPI shared and exclusive output.
- Gapless playback for continuous albums.
- Playlists and album-based track ordering.
- ReplayGain and loudness normalization.
- English and Slovak interface.

## Download

Open the **Releases** section of this repository and download the file named **JustPlayAudioEx-<version>-Setup.exe** from the release assets.

The automatic **Source code (zip)** and **Source code (tar.gz)** downloads are repository archives, not the Windows installer.

## Windows compatibility

The application is designed for **Windows 11, 64-bit**. The installer also allows installation on Windows 10, 64-bit, but Windows 10 compatibility has not been verified.

## Installation

Close JustPlayAudioEx if it is running, launch the installer and follow its instructions. The installer offers installation for the current user or for all users.

## Third-party components

JustPlayAudioEx uses the BASS audio library and associated add-ons. Third-party notices are included with the application in the **ThirdParty** folder.
